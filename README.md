# Eustace the Pirate Monk

CS 2114 Project 1, Group 87. A text based pirate adventure game.

Run: build in Eclipse, then from the project folder `java -cp bin Game` (add a number,
such as `java -cp bin Game 3`, to seed the dice; `docs/demo.txt` is the seed 3 transcript).

Test: in Eclipse, right-click `src` and choose Run As → JUnit Test.

Documents: `DESIGN.md` is the scope, `SPEC.md` the specification, `PLAN.md` the build plan.
